# Kerwebuwe

Website der Deidesheimer Kerwebuwe (seit 1972).

- `index.html` – die komplette Seite (Design „Variante 3 · Dunkel / Immersiv“), aus dem Claude-Artefakt übernommen. Bilder und PDF sind derzeit direkt in die Datei eingebettet.

## Arbeitsweise

`main` ist der stabile Stand. Verbesserungen werden in eigenen Branches entwickelt und per Pull Request in `main` übernommen.
